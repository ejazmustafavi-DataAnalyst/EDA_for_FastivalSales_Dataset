# Festival Sales Data EDA

This project demonstrates exploratory data analysis (EDA) on a festival sales dataset using Python. The goal is to extract business insights from customer behavior, sales patterns, and product performance to support better sales, marketing, and inventory decisions.

## Project Files

- `sales_eda.ipynb` — main notebook with the full analysis, visualizations, and code.
- `FastivalSalesData.csv` — dataset used for the analysis.

## Project Overview

The notebook includes:

- Data loading and initial inspection
- Data cleaning and preprocessing
- Feature renaming for clarity
- Summary statistics for sales and order metrics
- Visual analysis of sales across demographics and categories
- Business-focused insights based on the findings

## Tools Used

- Python
- pandas
- numpy
- matplotlib
- seaborn

## Key Insights

- Cleaned and prepared the festival sales dataset for analysis.
- Measured total sales and compared performance across customer segments.
- Analyzed sales by gender, age group, marital status, occupation, state, product category, and product ID.
- Identified top-performing categories and customer segments for more targeted marketing.
